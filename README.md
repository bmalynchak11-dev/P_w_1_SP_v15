# Стартовий проєкт SP-P01

1. Відкрийте проєкт у GitHub Codespaces (Code → Codespaces → Create codespace) або локально в Linux: `python3 -m venv .venv`, `source .venv/bin/activate`, `pip install -r requirements.txt`, `sudo apt install strace procps`.
2. Визначте свою задачу за номером варіанта (таблиця в інструкції) і реалізуйте її у файлі `variants/variant_TT.py`.
3. Запускайте відкриті тести свого варіанта: `pytest --variant 17` (замініть 17 на свій номер).
4. Змінюйте лише свій файл у `variants/` (і за бажанням `tests/test_my.py`).
